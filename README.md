# 🏥 MediMate

 ### AI-Powered Medication Management & Health Analytics Platform

A full-stack healthcare platform that helps patients manage medications, analyze prescriptions and lab reports using AI, track health records, and receive intelligent medication reminders.

🔗 **Live Demo:** https://medimate-frontend-09uz.onrender.com

💻 **Tech Stack:** React • Django • Django REST API • SQLite • OCR • AI

---

# 📌 Project Overview

Healthcare management often involves maintaining prescriptions, remembering medications, understanding laboratory reports, and tracking health records.

MediMate addresses these challenges by providing an intelligent healthcare platform capable of:

- Managing patient medical records
- AI-powered prescription analysis
- Medicine reminder management
- Lab report interpretation
- OCR-based document scanning
- Personalized health dashboard
- Secure patient profile management

# ⚙️ Installation

## Backend

```bash
cd backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```
